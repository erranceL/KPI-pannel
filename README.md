# KPI 面板

研发绩效积分管理面板,实现《研发绩效积分办法 v2.2(试行)》的全部计分、扣分、公示与年度分配规则。

## 制度版本对应

- 当前实现:**v2.2(试行)**,全文内置于「制度」页(`src/assets/policy.md`)。
- 制度修订时:更新 `src/assets/policy.md`,并同步调整 `src/lib/rules.ts` 中对应的计算口径。

## 功能

| 页面 | 对应条款 | 说明 |
| --- | --- | --- |
| 月度看板 | 8.x | 月度总分 = 正分 + 运维杂项 − 扣分 − Lead 连带;实名明细 / 匿名排名 / 总分区间三种视图;月度归档锁定 |
| 积分台账 | 3.x | 四档定分、大档 25/30 强制理由、特大档待确认流转、交付系数、重排期计数、多人拆分校验(总分不超档位)、运维杂项每月一笔、自修不计分 |
| 问题与事故 | 4.x / 5.x / 7.x | 扣分 = 档位 × 责任 × 报告,实时封顶校验(近 12 个月正分 ×40%、入职不满 6 个月年化折算、红线不适用)、新人扣分减半、Lead 连带 30%、小问题 30 天同类重复升级提示 |
| 年度视图 | 9.x | 年度有效积分 = max(正分 − 扣分, 0);评级辅助(P0 主责封顶 B、红线暂缓);年终奖模拟器(分母为全员正分总和,留存不二次分配,3 倍均值复核);Token 五系数模拟器(风险系数按事故自动建议) |
| 试运行观察 | 10.1 | 大档占比、重排期、小问题重复未改进、各端定档尺度分布 |
| 团队设置 | — | 成员管理(端别/角色/职级/入职日期)、JSON 导入导出、重置演示数据 |
| 制度 | — | v2.2 全文 + 速记卡 |

## 角色与权限

顶部左下角可切换当前身份(成员 / Lead / 架构师 / CTO),控制可见性与操作:

- **成员**:只读本人明细 + 匿名/区间公示
- **Lead**:可记积分台账、记录小问题
- **架构师**:+ 确认特大档、认定 P2、月度归档
- **CTO**:+ 认定 P0/P1、红线标记

> 注意:无后端前这只是 UI 层约束,真实鉴权待后端实现。

## 技术栈

React 19 + Vite + TypeScript + Tailwind CSS 4 + React Router + Zustand。

```bash
npm install
npm run dev      # 本地开发
npm run build    # 产物在 dist/,可部署到内网静态服务器
```

> 数据含薪酬敏感信息,不建议公网部署;本地 `npm run dev` 或内网部署 `dist/` 即可。

## 数据与后端对接

- 当前数据保存在浏览器 `localStorage`,可通过「团队设置 → 导出/导入 JSON」在成员间同步。
- 数据层采用适配器模式(`src/data/adapter.ts` 的 `StorageAdapter` 接口):后端就绪后实现 `RestApiAdapter` 并在 `src/store.ts` 替换即可,页面层无需改动。
- 全部计算口径为纯函数,集中在 `src/lib/rules.ts`,后端落地时直接移植该文件即为同一口径。
- 建议后端按实体拆分 REST 资源:`/members` `/scores` `/incidents` `/archives` `/annual`。

## 目录结构

```
src/
  lib/types.ts        # 实体类型(与 v2.2 条款一一对应)
  lib/rules.ts        # 纯函数计算器(计分/扣分/封顶/年终奖/Token/观察指标)
  data/adapter.ts     # StorageAdapter 接口 + LocalStorageAdapter
  data/seed.ts        # 演示种子数据
  store.ts            # Zustand 状态 + 前端权限辅助
  pages/              # 7 个页面
  components/         # 布局与通用 UI
  assets/policy.md    # 制度 v2.2 全文
```
